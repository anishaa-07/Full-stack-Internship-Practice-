01 / Fixed & Sticky Layout

This heading uses position: sticky; top: 60px;, so once it reaches 60px from the top of the viewport (right below the fixed navbar) it locks in place while the rest of this section keeps scrolling underneath it.

position: fixed is different — the navbar above never moves at all, no matter how far you scroll, because it's pinned relative to the viewport, not the document. That's why we added padding-top: 60px on the body — otherwise the fixed nav would sit on top of and hide this very first line of content.

Notice the difference: fixed = always locked to screen. sticky = locked only after scrolling past its normal position, and only within its own parent container.

02 / Custom CSS Tooltip

Hover over this badge to see a tooltip appear: Hover me position: absolute inside position: relative parent!

The trick: the badge's parent (.tooltip) is set to position: relative, which creates a positioning context. The tooltip text itself (.tooltip__text) is position: absolute, so it positions itself relative to that nearest relative ancestor — not the whole page. By default it's hidden with visibility: hidden and revealed with a smooth opacity transition on :hover.

03 / Float & Text Wrap

This paragraph's text wraps naturally around the floated image on the left, exactly the way float was originally designed to be used back before Flexbox and Grid existed — for magazine-style text wrapping around a picture. The image is pulled out of normal document flow with float: left, and every inline-level box beside it (like this text) flows around its remaining space.

Once the paragraph text runs longer than the image's height, it continues at full width below the image, because the float only affects the box while its vertical span overlaps the floated element. This is the classic behaviour that made floats useful for editorial layouts, even though modern layout work now leans on Flexbox and Grid for anything structural.

A clearfix (.container::after { content:""; display:block; clear:both; }) is applied on this section so the floated image doesn't spill out and break the layout of whatever section comes after it.
