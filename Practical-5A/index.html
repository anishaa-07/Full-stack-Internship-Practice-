02 Typography Scale

Headings sized with rem units so they scale consistently with the root font size.

H1 — Heading One 2.75rem

H2 — Heading Two 2.1rem

H3 — Heading Three 1.5rem

Body paragraph text sits at the base 1rem size with a comfortable 1.6 line-height for readability.
