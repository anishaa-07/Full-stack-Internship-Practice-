Grid Named Areas: Designing Like a Newsroom

By Anisha · Full-Stack Internship · Practical 8A

Long before CSS Grid existed, print magazines were already solving the exact problem it solves today: arranging text, images, and pull-quotes into a structured, multi-column page that still reads naturally from top to bottom. grid-template-areas is, in a sense, CSS finally catching up to what paste-up artists were doing with physical layout boards decades ago.

The lead image above uses grid-column: span 2, so instead of occupying a single track like the paragraphs beside it, it stretches across two of the article's three columns — exactly the kind of dominant, attention- grabbing treatment a lead photo gets on a real magazine spread.

Every gutter you see on this page — between columns, between rows, between the header and the body — comes from a single gap declaration on each grid container. There isn't a single margin hack anywhere in this layout; every bit of spacing is Grid's own gutter system.

Because grid-template-areas names each region of the page directly in the CSS — header, sidebar, article, ads, footer — the HTML stays completely flat and semantic. There's no need for wrapper divs whose only job is to create a layout hook; the grid areas do that work instead.

This is also why the whole page collapses gracefully on mobile: the media query at 600px simply redefines grid-template-areas with the regions stacked in a single column, and every element automatically re-flows into its new position — no restructuring of the HTML required at all.
